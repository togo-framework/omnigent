# omnigent

See the [main README](../README.md). Full framework docs: https://github.com/togo-framework/togo/tree/main/docs

A togo **impl** provider (autopilot's `impl` slot) that implements issues via the
Omnigent `omni` CLI, run through the Env — so with exec=coder it runs inside the
Coder workspace. Select with `togo provider:use impl omnigent`.
